# School Minimarket Mobile Platform

This repository contains the full source code for the **Indonesian school minimarket** solution:

- **Android client** (`app/`): Kotlin + Jetpack Compose app for students, teachers, and staff.
- **Backend API** (`backend/`): ASP.NET Core Web API with EF Core, JWT auth, and basic analytics.
- **Admin UI** (`admin-ui/`): React web panel for cashiers and administrators.
- **Documentation** (`docs/`): Architecture, requirements, API spec, and development guide.

The project follows a clean‑architecture approach and uses role‑based access control. See the `docs/` folder for detailed design.
